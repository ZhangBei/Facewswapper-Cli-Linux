# (driver 570+). On an older driver, use the cu126 or cu124 index URL
# instead - the code does not care which CUDA minor version is present.

# Model ONNX files are NOT pip-installable. Place them in the models
# folder: det_10g.onnx, w600k_r50.onnx, inswapper_128.fp16.onnx (minimum).
